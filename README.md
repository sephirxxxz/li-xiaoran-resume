## 研究 Memo：AI Agent 的上下文、记忆与可靠检索

[下载研究 Memo（DOCX）](./li-xiaoran-research-memo.docx)

### 内容概览

这份 Memo 横向研究了三个处于不同层次的 AI Agent 上下文产品：Coast、Zaro 与 PageIndex，关注它们如何获取、组织、记忆、检索和验证上下文，以及这些能力能否形成高频使用、商业化与长期壁垒。

| 项目 | 研究重点 | 初步判断 |
| --- | --- | --- |
| **Coast** | 个人桌面上下文、截图、OCR 与检索 | 单一截图研究工作流已有明确价值；需验证跨应用、跨 Session 的长期记忆与主动复用。 |
| **Zaro** | 企业共享上下文、数据连接与 Agent 工作空间 | 企业痛点真实、平台愿景较大；需先证明具体高频工作流、留存、ROI 与付费。 |
| **PageIndex** | 专业长文档的文档树、推理式导航与可验证引用 | 技术切入口和专业场景较清晰；应优先验证端到端准确率、单位经济、付费客户与部署能力。 |

### 研究范围与方法

Memo 基于产品体验、公开产品资料、官网与 GitHub 信息，以及与 FDE 的交流进行初步判断。分析覆盖产品定位、核心工作流、采用成本、准确率与基础设施成本、商业化路径、竞争替代和潜在长期壁垒。

### 关键结论

- **Coast** 已验证桌面上下文捕捉、OCR 和检索在网页研究工作流中的价值，但尚不能据此确认其已经成为可跨应用、跨 Session 复用的长期个人记忆层。
- **Zaro** 连接企业信息并让 Agent 读写共享工作空间的方向重要，但宽泛的平台能力仍需要收敛到一个高频、刚性且不可替代的核心工作流。
- **PageIndex** 面向金融、法律、研究等专业长文档，强调结构理解、证据定位和可审计引用；其长期价值取决于专业文档基础设施、企业能力和单位经济能否抵御模型厂商内置功能与开源复制。

### 局限与下一步验证

这是基于当前信息的初步研究判断，不构成完整的商业或投资结论。Memo 尚未完成系统性的客户访谈、长期留存验证、端到端准确率测试、单位经济测算或付费客户数据核验；上述证据应作为后续重点验证方向。
